# New API 二开版（订阅账号）

基于官方 [QuantumNous/new-api](https://github.com/QuantumNous/new-api) **v1.0.0-rc.47** 二次开发，分支 `feat/subscription-accounts`。
对接 CPA（CLIProxyAPI）**v8.0.51** 管理接口，把 CPA 上 Claude 订阅账号的额度、状态、用量集中放到 New API 里查看和管理。

原则：**只新增、不改原功能**。官方功能和用法不变，官方文档请看上游仓库。

- 镜像：`ghcr.io/fylsan3/new-api:v1.0.0-rc.47-sub.66a8ab26`（x86_64，公开）
- 详细技术说明：[CHANGES-SUBSCRIPTION.md](./CHANGES-SUBSCRIPTION.md)

## 我新增 / 修改了什么

### 1. 新菜单「订阅账号」（仅超级管理员）

- 管理员区「渠道」上方新增菜单，菜单、路由、后端接口三层限制，只有超级管理员能看能用。
- **CPA 管理**：可添加多台 CPA（名称 + 管理地址 + 管理密码），密码加密保存、页面只显示 `****`；支持测试连接、同步账号。删除 CPA 只删本页记录，不动 CPA 上的账号。
- **账号卡片**：套餐标签、启用开关、5 小时 / 7 天 / Opus / Sonnet 等额度条（剩余 ≥70% 绿、≥30% 黄、<30% 红）、剩余重置次数（>0 时红框置顶）、成功 / 失败数、最近请求。
  - Claude 账号用 Claude 风格：暖白卡底、陶土色图标 / 标签 / 开关、衬线标题。
  - 未配置 socks5 的账号显示「直连」标签。
- **悬停详情框**：鼠标停在卡片上弹出，含文件名（可复制）、所属 CPA、代理（打码）、请求统计、近 30 天 token 分项、消费、各额度重置时间；额度查询超过 1 小时标黄。
- **按钮**：模型、刷新、启用 / 关闭（二次确认）、使用重置卡（仅有剩余次数时显示，二次确认）。
- **对话额度（2026-11-06）**：每次对话结束后 CPA 会记下 Anthropic 返回的 5 小时 / 7 天额度，页面每 5 秒拿一次显示到卡片上，不用点刷新。额度条下方小字标明来源（「来自对话」绿点 /「来自刷新」灰点 + 多久前），取较新的一份；被限流显示红色「已限流」，重置时间已过显示「已重置」。Opus / Sonnet 等细分额度仍以手动刷新为准。
- **刷新**：
  - 额度、套餐**只能手动刷新**（单卡刷新会顺带同步凭据信息）。全部刷新时请求在 5–10 秒内错开发出，冷却默认 / 最低 1 分钟，按钮显示倒计时，鼠标悬停 5 秒弹出冷却设置。
  - **每日随机刷新**：每个账号每天随机 1 或 2 次（各 50%）、全天随机时刻，两次至少隔 4 小时，**只查套餐类型和重置次数，不查额度**；没配 SOCKS 或 SOCKS 不通直接跳过，不直连。悬停详情显示「下次自动刷新」时间。原「后台自动刷新」开关已去掉。
  - 成功 / 失败数、最近请求等凭据信息后台每 5 秒同步；页面每 5 秒刷新。
- **审计日志**：CPA 增删改、账号启停、重置额度、设置修改等操作都会记录。

### 2. 账号安全（SOCKS 守卫）

- 发往 Anthropic 的请求全部经 CPA 代发，走该账号自己的代理，New API 不直连 Anthropic。
- 每次发请求前都会重新读取账号代理：
  - 配了 `socks5://` / `socks5h://` → 放行；
  - 代理写了但格式不对（http、direct、缺端口等）→ **拦截，不发请求**，防止 CPA 悄悄改成直连暴露真实 IP；
  - 完全没配代理 → 只放行只读的额度查询（这类账号是有意直连的），刷新 token、使用重置卡仍然拦截。
- SOCKS 连接失败一次即自动停用该账号并产生告警，需要手动确认。
- 页面和接口拿不到任何 token。

### 3. 用量采集（每台 CPA 单独开关，默认关）

- 在「编辑 CPA」里打开「采集用量」（未开启显示橙黄、采集中显示绿色），每 5 秒从 CPA 用量队列取记录。需要 CPA 系统参数里的「用量统计」也打开。
- 开启后可看到每个账号的 token、消费，「最近请求」接近实时；数据按小时汇总保留 90 天，额度点保留 14 天。
- 注意：用量队列只能被一个程序读取，有别的程序在读时请保持关闭。

### 4. 概览页与仪表盘

- 概览页（仅超管）：订阅账号告警横幅、账号池健康条、错误率（24h）卡片；**去掉了官方的「开始使用 / 推荐操作」设置引导**。
- 仪表盘新增「订阅账号」分区：账号对比表、7 天额度趋势、成本 vs 收入（估算）。
- 模型分析、流向图支持按渠道筛选（可选「仅 CPA 渠道」）；流向图新增 CPA 账号层（按 token 占比估算）。

## 部署

### 全新安装（x86_64 Linux + Docker）

从 [Releases](https://github.com/fylsan3/new-api/releases) 下载 `install-newapi.sh`：

```bash
chmod +x install-newapi.sh
sudo ./install-newapi.sh            # 默认装到 /opt/new-api，端口 3000
# 可改：APP_DIR=/data/new-api PORT=3001 sudo -E ./install-newapi.sh
```

- 目录里已有安装或已有 `new-api` 容器时会直接退出，不会覆盖。
- 自动生成随机 `SESSION_SECRET`，安装完成后做健康检查。

### 升级已有安装

从 Releases 下载 `update-newapi.sh`，在 compose 所在目录执行：

```bash
./update-newapi.sh              # 升级到脚本内置版本（自动备份 compose 和 data）
./update-newapi.sh --rollback   # 回滚到升级前
./update-newapi.sh --check      # 查看当前版本和状态
```

只改 `docker-compose.yml` 里 new-api 的 `image:` 一行，其他参数不动。

### 说明

- 建议设置 `CRYPTO_SECRET`（用于加密 CPA 管理密码；未设置时用 `SESSION_SECRET`）。更换后需重新填写 CPA 管理密码。
